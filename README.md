## Descripción de aplicación 

<p align="justify">
 La aplicación consiste en extraer la información de cuatro tienda con el fin de analizar las ventas

 de cada tienda y recomendar cual tienda puede puede ser remobidad para invertir en otro negocio. 

 Para el análisis se elaboran gráficos para visializar mejor la información.

</p>

## Procedimiento

:heavy_check_mark: `Ingresos:` Obtener ingresos totales de cada tienda.

:heavy_check_mark: `Ingresos por Categoría:` Obtener ingresos por Categoría pro tienda.

:heavy_check_mark: `Graficos:` Generar gráfico de barras de Ingresos por Tienda y Generar gráfico de pastel para mostrar mostrar el porcentaje de ingresos por tienda.

:heavy_check_mark: `Calificación:` Obtener la calificación promedio por Tienda

:heavy_check_mark: `Gráfico:` Generar gráfico de barras para mostrar la calificación promedio por Tienda 

:heavy_check_mark: `Productos mas y menos vendidos:` Obtener la cantodad de productos mas y menos vendidos por Tienda

:heavy_check_mark: `Costo de envío:` Obtener el costo promedio de envío por Tienda

:heavy_check_mark: `Gráfico:` Generar gráfico de barras para mostrar el costo promedio de envío por Tienda
